# Quake / DMC / DMQ Archive

This archive contains a large and rare collection of content related to **Quake**, **Deathmatch Classic (DMC)**, and **DMQ**.  
Many of these files originate from old community servers, personal map packs, and tools that are no longer available online.  
The purpose of this archive is to preserve historical content from the Quake modding and mapping scene, including maps, mods, tools, textures, sounds, and documentation.

Examples: `07.bsp`, `hoppa2.bsp`, `maphub_v1.bsp`, `trick.bsp`, `trix.bsp`
